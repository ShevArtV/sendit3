SendIt
--------------------
Author: Shevchenko Artur <shev.art.v@yandex.ru>
--------------------

SendIt - компонент для работы с формами на сайте.

Событие siOnSanitizeFileName
--------------------------------
Вызывается на validate_files до приёма чанков. Параметры: name (оригинал), sanitized
(имя по правилам пакета), extension, directory, context=upload, formName, presetName, SendIt.
Проект может вернуть имя через $modx->event->returnedValues['name'], в том числе с
относительным подкаталогом. Ответ всегда повторно фильтруется: traversal срезается,
исполняемые расширения обезвреживаются, итоговый путь остаётся в каталоге сессии.

!!!ВАЖНО!!! При установке компонент так же будут установлены pdoTools и FormIt.

Возможности:
1. Отправка данных полей форм на сайт без перезагрузки страницы.
2. Загрузка файлов любых размеров на сервер и прикрепление их к письмам.
3. Создание опросников (многошаговых форм)
4. Сохранение данных форм в localStorage и заполнение полей после перезагрузки.
5. Есть авторизация, регистрация, восстановление пароля и редактирование личных данных.

Особенности:
1. Использует cookie и localStorage.
2. Не требует вызова сниппетов для отправки формы.
3. Есть защита от ботов и внешнего доступа.
4. Можно корректировать работу с помощью событий.
5. Отправка возможна на события change и input.

--------------------
SQL-инъекции
--------------------
SendIt отклоняет известные SQLi-последовательности до вызова snippet-а и возвращает
обычную ошибку формы. Это дополнительный барьер, а не способ безопасно подставлять
значения в SQL.

Значения полей не экранируются для SQL и не должны передаваться в raw SQL. Snippet,
который читает $_POST, обязан использовать xPDO criteria или подготовленные выражения
с bind-параметрами. Не фильтруйте SQL-токены вырезанием: это портит легитимный текст и
не закрывает другие варианты инъекции.

--------------------
Восстановление пароля
--------------------
Пресет forgot отправляет пользователю ссылку подтверждения. Новый временный пароль
применяется на странице activationResourceId сниппетом PasswordReset по параметру ?rp=.

Сниппет должен быть вызван некешируемо. Если на странице нужно показать новый пароль,
сохраните результат сниппета в переменную и выведите temp_password из extended:

{set $resetResult = '!PasswordReset' | snippet: []}
{if $resetResult}
    <p>Пароль изменён.</p>
    {if $resetResult.extended.temp_password}
        <p>Новый пароль: <strong>{$resetResult.extended.temp_password}</strong></p>
    {/if}
{/if}

Временный пароль хранится в профиле до истечения срока ссылки. Повторный переход по
ссылке в пределах этого срока выставляет тот же пароль.
